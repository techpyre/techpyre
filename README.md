## Chi Siamo

**TechPYRE** è uno studio indipendente di ingegneria del software dedicato alla progettazione di architetture web proprietarie ad alte prestazioni (Next.js, TypeScript, Cloudflare Edge) per PMI e aziende B2B.

### Principi Operativi
* **Interlocutore tecnico diretto:** Dialogo 1:1 con chi progetta, ingegnerizza e rilascia il codice.
* **Caricamento sub-secondo:** Architetture statiche ed Edge orientate a Core Web Vitals elevati, riducendo i contatti persi sui flussi pubblicitari.
* **Tempi e costi definiti:** Sprint a prezzo fisso per landing page e roadmap concordate per ecosistemi complessi.
* **Proprietà integrale del codice:** Codice standardizzato ceduto al cliente, senza lock-in tecnologico né canoni di licenza ricorrenti.

## Stack Tecnologico

```
Frontend & Core:         Next.js (App Router, React 19, TypeScript)
Styling & UI:            Tailwind CSS v4, Framer Motion, Responsive Semantic Design
Data & Backend:          PostgreSQL, Prisma ORM, REST API con validazione idempotente
Resilienza & Edge:       Cloudflare Workers, Edge Caching, IndexedDB Offline Queues
Pagamenti & Fisco:       Stripe API (3-D Secure, SEPA Direct Debit B2B), Webhook HMAC, Tracciato FatturaPA (SDI)
```

## Aree di Intervento

1. **Siti Web & Ecosistemi Digitali Completi:** Progettazione e ingegnerizzazione di siti aziendali ad alte prestazioni orientati a posizionamento e lead generation.
2. **Portali Ordini B2B & Listini Complessi:** Aree riservate per clienti e reti vendita con listini a scaglioni, gestione agenti, fido e fatturazione elettronica.
3. **Landing Page ad Alta Conversione:** Pagine verticali per linee di prodotto o servizio con form resilienti e pre-qualifica.
4. **Audit Tecnico & Refactoring Performance:** Eliminazione di framework obsoleti o CMS lenti con migrazione a stack statici ed Edge.

## Configurazione Locale

1. Copia `.env.example` in `.env.local` e configura le variabili richieste.
2. Installa le dipendenze con `npm install`.
3. Avvia il server di sviluppo con `npm run dev` o la build di produzione con `npm run build`.
